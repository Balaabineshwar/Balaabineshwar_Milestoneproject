 Olist E-Commerce Data Analytics Milestone Project



An end-to-end data analytics portfolio project examining the Brazilian Olist E-Commerce dataset, covering data acquisition, cleaning, relational database design, statistical analysis, interactive dashboarding, and executive reporting.





 Project Overview

This project investigates customer behavior, sales performance, delivery efficiency, and product trends using real-world Brazilian e-commerce data from Olist. It translates raw multi-table transactional data into actionable business insights through a structured end-to-end analytics workflow.



 Tools \& Technologies Used

Python: Pandas, NumPy (Data cleaning, preprocessing, and statistical analysis)

Jupyter Notebook: Documenting data acquisition and exploration workflows

SQL (MySQL / MySQL Workbench): Relational data querying, aggregation, and filtering

Microsoft Excel: Advanced data structuring, pivot tables, formulas, and reporting workbook

Power BI / DAX: Data modeling, relationships grain enforcement, and interactive business intelligence dashboarding

AI-Assisted Analytics: Synthesizing technical workflows and documenting business findings

Reporting: Executive PowerPoint presentation and comprehensive business insights report
