# 📊 Olist E-Commerce Data Analytics Project

## 🚀 End-to-End Data Analytics Using Python, Excel, SQL, Statistics & Power BI

This project analyzes Brazilian e-commerce data from Olist to understand sales performance, customer behavior, payment patterns, delivery operations, seller performance, and customer satisfaction.

It demonstrates an end-to-end data analytics workflow, from data acquisition and preparation to analysis, visualization, and business reporting.

---

## 🎯 Project Objectives

* 📈 Analyze sales and revenue performance.
* 👥 Understand customer purchasing behavior and retention.
* 🚚 Evaluate delivery performance and order fulfillment.
* 💳 Analyze payment patterns and transaction values.
* ⭐ Explore customer satisfaction through review ratings.
* 🛍️ Investigate product and seller performance.
* 📊 Build interactive dashboards and communicate business insights.

### 📂 Open the Power BI Project Folder
**How to view the dashboard:**
1. Open the `05_PowerBI` folder.
2. Download `Balaabineshwar_PowerBI.pbix`.
3. Open the file using Microsoft Power BI Desktop.

*Note: GitHub does not render .pbix files as interactive dashboards in the browser. Download the file to explore the full report in Power BI Desktop.*
